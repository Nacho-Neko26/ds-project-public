# workspace/（运行数据，不进仓库）

这个目录里装的是机器人的**运行数据**，由程序自己生成和维护，公开模板里只留空壳：

| 子目录 | 内容 |
|---|---|
| `incoming/` | 收到和发出的图片、语音临时文件 |
| `diary/` | 每天自动写的日记 |
| `memory/` | 长期记忆（memories.jsonl） |
| `profiles/` | 认人档案、好感度、昵称表 |
| `stickers/` | 收藏的表情包索引与素材 |
| `summary/` | 群聊摘要 |
| `habits/` | 群里的说话习惯统计 |
| `.dsh-knowledge/` | 群聊知识库 |
| `.dsh-meow/` | 记忆插件数据库 |

**这里的任何东西都不要提交到公开仓库** —— 里面有群友的 QQ 号、聊天内容、号主的私事。
部署后它会自己长出来；`deploy/install.sh` 对 `workspace/` 只补不覆盖，重复跑不会冲掉现有数据。
