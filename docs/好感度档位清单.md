# 好感度 × 指令 权限对照表

> 2026-10-25 起，**一项能力 = 一个分数门槛**，代码里统一走 `config.json → agent.favorThresholds`。
> 号主（祈羽 `<OWNER_QQ>`）和 `trusted` 名单里的人**不看分，全部放行**。

## 一、总表

| 分数 | 能干什么 | 代码键 |
|---|---|---|
| 初始 **50** | 正常聊天、接梗、查天气/翻译/算数、被点名回话 | — |
| **20** | 恢复正常：不再见你就上火 | `FAVOR.hate` |
| **35** | 让她发语音 | `voice` |
| **50** | 让她发表情包 / 黄脸 | `sticker` |
| **70** | 设定时提醒；`#名称` 工作项（任意指令） | `remind` / `command` |
| **80** | 点歌、转发素材、记事本「关于你」、工作项给出写权限 | `music` / `media` / `notebook` / `strict` |
| **90** | 可以点她唱（她自己唱，不只是放歌） | `sing` |
| **任何人** | `#好感度` / `#心情` | 固定命令，不设门槛 |
| **仅号主** | `#同步`、群管理（撤回/禁言/改名）、`__NICK__` 改别人称呼 | 号主专用 |

## 二、按能力拆开看

| 能力 | 门槛 | 不够时她会说 |
|---|---|---|
| 普通聊天、接梗、查资料 | 无 | — |
| 发语音 `__SEND_VOICE__` | 35 | 「这轮不发语音：这人好感还不到 35」 |
| 发表情 `__SEND_STICKER__` | 50 | 提示词里连目录都不列，模型不会发 |
| 定时提醒 `__REMIND__` | 70 | 「设提醒得等好感 70 以上，你还差 X 分」 |
| `#任意名称` 工作项 | 70 | 「这条得等好感 70 以上才办（现在 X）」 |
| 点歌 `__MUSIC__` | 80 | 「点歌得等好感 80 以上，你还差 X 分」 |
| 转发素材 `__SEND_MEDIA__` | 80 | 「转发素材得等好感 80 以上，你还差 X 分」 |
| 记事本 / 「关于你」 | 80 | 不给注入，模型不知道这些内容 |
| 工作项的文件写权限 | 80 | <80 强制 `read-only`，只能查不能改 |
| 点她唱 | 90 | 「可以点歌，但唱还不行」 |

## 三、怎么改

改服务器 `qq-agent/config/config.json`，**只动数字，别删键**：

```json
"agent": {
  "favorThresholds": {
    "command": 70, "voice": 35, "sticker": 50, "remind": 70,
    "music": 80, "media": 80, "notebook": 80, "about": 80,
    "strict": 80, "sing": 90
  }
}
```

改完必须：`node -e "JSON.parse(require('fs').readFileSync('config/config.json','utf8'))"` 验一遍
→ `systemctl restart qq-bridge`（配置只在启动时读）。

## 四、实现位置

| 位置 | 干什么 |
|---|---|
| `qq-agent/src/favor.mjs` `renderFavorCard()` | `#好感度` 卡片，每 10 分一档列出解锁项 |
| `qq-agent/src/agent.mjs`（约 431-450 行） | 把「这人现在够哪几档」写进提示词 |
| `qq-agent/src/index.mjs` `FAVOR_TH()` 等 | 各门槛取值；`favorCapabilityHint()` 汇总成一句给模型 |
| `qq-agent/src/index.mjs` `actionGate()` | `/api/action` 的 `by` 发起人校验 |

## 五、怎么加分（回顾）

- 每天聊过一句且没惹她：04:00 日结 **+5**
- 聊天时每小时结算 **+1**（每天这条最多 5 分）
- 被夸 **+1** / 被惹 **-1**
- 单日总加分封顶 20；好感 <50 的人涨速减半
- 被别人劝说（低好感的人被 70+ 的人劝）：**+5**
